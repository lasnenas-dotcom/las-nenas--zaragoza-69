# Las Nenas de Zaragoza 69 — plantilla

Esta es una plantilla estática editable. Abre `index.html` para verla.
- Cambia textos y colores en `index.html` y `style.css`.
- Cambia perfiles y fotos en `script.js`.
- Para convertirla en una web real con cuentas, subida de fotos, moderación y base de datos necesitarás un backend y almacenamiento seguro.
- El sitio debe limitarse a adultos (18+) y cumplir las leyes y normas aplicables.
